# 部署教程（新服务器）

从零在一台 Linux 服务器上装好机器人 + 面板 + 地图服务，然后用 App 管理。

---

## 零、准备

| 项 | 要求 |
| --- | --- |
| 系统 | Ubuntu 22.04 / 24.04（脚本按 `apt` 写；CentOS 需手动装 Java 21） |
| 内存 | 1 GB 起步（脚本内存 <2G 会自动加 2 GB swap） |
| 磁盘 | 3 GB 以上 |
| 权限 | root |
| 端口 | TCP **8080**（面板，App 必需）、**25565**（玩家进服）、**8081**（删图，可选） |

服务器上先装 git（若有则跳过）：

```bash
apt update && apt install -y git
```

---

## 一、拿代码 + 下依赖

```bash
git clone <你的仓库地址> botctl
cd botctl

# 下载上游两个 jar 并做 SHA256 校验（不进 Git）
bash scripts/fetch-upstream.sh
```

国内服务器连 GitHub 慢的话用镜像：

```bash
bash scripts/fetch-upstream.sh --mirror    # 走 gh-proxy.com
```

成功后 `dist/` 里会有：

```
ZenithProxy.jar                60.5 MB
ZenithProxy-WebUI-1.4.0.jar     4.7 MB
```

> 这两个是上游 AGPL 组件，本仓库不分发，只负责下载校验。见 [../NOTICE](../NOTICE)。

---

## 二、一键部署

```bash
sudo bash server/deploy_zenith.sh --server 你的目标服地址
```

`--server` 是机器人要连的 MC 服务器（默认 `2b2t.org`）。也可以直接跑 `deploy_zenith.sh`
然后事后在 App 的「功能 → 目标服务器」里改。

常用参数：

| 参数 | 说明 |
| --- | --- |
| `--server <地址>` | 目标 MC 服务器 |
| `--password <密码>` | 面板密码（不给则随机生成 16 位） |
| `--panel-port <端口>` | 面板端口，默认 8080 |
| `--map-port <端口>` | 删图服务端口，默认 8081 |
| `--proxy-ip <IP/域名>` | 显示给玩家的代理地址（不给则自动探测公网 IP） |
| `--dir <目录>` | 安装目录，默认 `/root/ZenithProxy` |
| `--no-offline` | 不启用离线玩家支持（`verifyUsers` 保持 true） |

脚本做的事：

1. 装 Java 21 / python3 / tmux / curl
2. 内存不足时建 2 GB swap
3. 放 jar、写面板配置（认证开启、随机密码、**关掉 authBypasser**）
4. 建 `web/maps` 软链，让地图能走面板端口
5. 装地图索引定时器 + 删图服务
6. 三个 systemd 单元，全部开机自启
7. 启动并配置目标服、监听端口、自动重连、关自动更新
8. **关掉 `verifyUsers`**（离线玩家能连代理的前提）
9. 自检并打印面板地址 / 用户名 / 密码

跑完你会看到：

```
==============================================================
 部署完成
==============================================================
 面板地址   : http://1.2.3.4:8080
 面板用户名 : admin
 面板密码   : Kx7mPq2Rt9Vw4ZbN
 地图服务   : 端口 8081
 安装目录   : /root/ZenithProxy
 自检       : 面板登录 HTTP=200
              地图服务 HTTP=200
              机器人     connected=False user=Unknown
==============================================================
```

`connected=False` 正常——还没登录微软账号，下一步在 App 里点上线。

**把三行凭据抄下来。**

---

## 三、开防火墙

云控制台放行 TCP：`8080`、`25565`（要删图再加 `8081`）。

- 阿里云轻量：控制台 → 防火墙 → 添加规则
- 阿里云 ECS / 腾讯云 / AWS：安全组入方向

> 建议把 8080/8081 的**来源限制成你自己的 IP**。面板走明文 HTTP，公网直开等于把密码摊在网上。

---

## 四、手机连上去

1. 装 `BotCtl-x.y.apk`
2. 「账号」页填：地址 `服务器IP:8080`、用户名 `admin`、密码（脚本打印的）
3. 点**保存并连接** → 状态页显示「● 离线」
4. 「账号」页 → 游戏账号 → 输入你的正版 ID → **添加** → 点该行 **切换**
5. 屏幕会出现微软设备码链接，手机浏览器打开授权
6. 回状态页点 **上线**，等到「● 在线」

> 同一微软账号只能一处在线。想自己进服玩，请连**代理地址**（`服务器IP:25565`），
> 别用同一账号直连目标服。

---

## 五、白名单

默认白名单是开的，**不加人谁也进不来**。

App →「白名单」页 → 输入游戏 ID → 添加。

⚠️ **离线 ID 加不进去**（插件要去 Mojang 解析 UUID，必然失败 `Could not resolve username`）。
离线名字必须手工写进 `config.json`，见下节。

---

## 六、六个实测坑

### 1. `authBypasser` 开着 → 正版号登不进

症状：`Unable to connect to login: Your username is already registered by an online account`。

原因：插件默认 `authBypasser: true`，把登录改写成离线形态，而正版名已被注册 → 冲突。
**部署脚本已默认关掉**。只有切离线账号时才需要打开。

### 2. 离线玩家连代理报「无效会话」

原因：`server.verifyUsers = true` 时代理会拿连接者身份去微软核验，离线客户端必失败。
**脚本已设 false**。这个没有命令入口，只能改文件，而且**必须先停服务再改**：

```bash
systemctl stop zenith
python3 - <<'PY'
import json
p='/root/ZenithProxy/config.json'
c=json.load(open(p)); c['server']['verifyUsers']=False
json.dump(c, open(p,'w'), indent=2)
PY
systemctl start zenith
```

运行中直接改会被 ZenithProxy 退出时的内存回写覆盖掉。

### 3. 离线名字进白名单

```bash
systemctl stop zenith
python3 - <<'PY'
import json, hashlib, time
name = '你的离线ID'
d = bytearray(hashlib.md5(("OfflinePlayer:" + name).encode()).digest())
d[6] = (d[6] & 0x0F) | 0x30; d[8] = (d[8] & 0x3F) | 0x80
h = d.hex()
uuid = '%s-%s-%s-%s-%s' % (h[0:8], h[8:12], h[12:16], h[16:20], h[20:32])
p = '/root/ZenithProxy/config.json'
c = json.load(open(p))
wl = c['server']['extra']['whitelist']['whitelist']
wl = [x for x in wl if x.get('username') != name]
wl.append({'username': name, 'uuid': uuid, 'lastRefreshed': int(time.time())})
c['server']['extra']['whitelist']['whitelist'] = wl
json.dump(c, open(p, 'w'), indent=2)
print('uuid =', uuid)
PY
systemctl start zenith
```

白名单**按 UUID 匹配，不是按名字**，改名后必须重算。

### 4. 机器人本体不能用离线账号连正版认证服

实测报 `Cannot join online mode server with offline auth`：这类服对客户端强制正版校验。
离线只对「玩家连代理」有效，对「代理连服务器」无效。

### 5. 地图页空白

```bash
systemctl status mapindex.timer                    # 每 20 秒写索引
ls -t /root/ZenithProxy/maps/index_*.json | head -3
```

插件的静态文件处理器**按路径永久缓存**（实测改同名文件 65 秒后仍是旧内容，加查询串也绕不过），
所以索引用带时间戳的 `index_<bucket>.json`，App 自己探测。

### 6. 地图删不掉

`8081` 没放行或 `mapadmin` 没起来。删图接口用**面板账号密码**鉴权——
因为面板令牌绑签发 IP，跨机重放无效。

## 七、日常运维

```bash
tmux attach -t zenith              # 机器人控制台（Ctrl+B 再 D 退出但不停）
systemctl status zenith mapadmin mapindex.timer
systemctl restart zenith           # 约 40 秒自动重连，不用重新扫码
tail -f /root/ZenithProxy/console.log

# 改面板密码（必须先停）
systemctl stop zenith
python3 -c "
import json;p='/root/ZenithProxy/plugins/webui/config.json'
c=json.load(open(p));c['auth']['password']='新密码';json.dump(c,open(p,'w'),indent=2)"
systemctl start zenith
```

**别开自动更新**（脚本已 `autoUpdate off`）：实测自动更新会去拉一个返回 500 的镜像，
反而把能跑的环境弄坏。升级请手动换 jar。

## 八、备份 / 迁移

搬服务器时这四个东西搬过去就能原样恢复（含免扫码登录）：

```bash
tar czf zenith-backup.tgz -C /root/ZenithProxy \
    config.json mc_auth_cache.json plugins/webui/config.json maps
```

| 文件 | 作用 |
| --- | --- |
| `config.json` | 全部运行配置（白名单、端口、模块开关） |
| `mc_auth_cache.json` | 微软令牌缓存 → **有它就不用重新授权**（等同凭据，勿外传） |
| `plugins/webui/config.json` | 面板端口与密码 |
| `maps/` | 已渲染地图（可选） |
